## About

Computer Science and Engineering student at **American International University-Bangladesh (AIUB)** with a strong interest in software development, database systems and practical application development.

I have built **desktop applications** in C# and Java, **web applications** in PHP, **databases** in Oracle, MySQL and SQL Server, **computer graphics** in C++ OpenGL, **data science** projects in R and **embedded systems** with Arduino. I also write my project reports in **LaTeX**.

## Projects

**Desktop Applications**
- [Farm Invoice Manager](https://github.com/munshi-rishad/CSharp-FarmInvoiceManager) – C# Windows Forms + SQL Server billing system with users, products, sales, invoices and sales report.
- [Desktop Calculator](https://github.com/munshi-rishad/CSharpLab-Desktop-Based-Calculator) – C# Windows Forms calculator with a dark design and keyboard support.
- [Coffee Shop Billing System](https://github.com/munshi-rishad/Java-CoffeeShopBillingManagementSystem) – Java Swing ordering and billing system with login and payment options.

**Web Application**
- [EduQuiz](https://github.com/munshi-rishad/WebTech-EduQuiz-Online-Quiz-Management-System) – PHP + MySQL (MVC) online quiz system for teachers, students and admins.

**Database**
- [Bus Ticket Counter Management](https://github.com/munshi-rishad/DataBase-BusTicketCounterManagement) – Oracle database with 9 related tables, queries and views, plus MySQL + Java JDBC.

**Computer Graphics**
- [Dreamland Village Ultimate](https://github.com/munshi-rishad/ComputerGraphics-Dreamland-Village-Ultimate) – C++ OpenGL animated village with day, sunset, night and rain scenes.
- [OpenGL Setup](https://github.com/munshi-rishad/ComputerGraphics-OpenGL-Setup) – ready-to-run OpenGL + FreeGLUT template for Code::Blocks.

**Data Science**
- [Twitter Sentiment Noise Robustness](https://github.com/munshi-rishad/DataScience-Twitter-Sentiment-Noise-Robustness) – R project testing BoW / TF-IDF classifiers on noisy tweets, with a research paper.
- [Stroke Data Cleaning and EDA](https://github.com/munshi-rishad/DataScience-Stroke-Data-Cleaning-Preprocessing-EDA) – cleaning, preprocessing and exploratory analysis of a stroke dataset in R.

**Embedded Systems and Digital Logic**
- [Gas Leakage and Fire Detection](https://github.com/munshi-rishad/Microprocessor-Arduino-Based-Gas-Leakage-and-Fire-Detection-With-Prevention-and-Safety-Mechanisms) – Arduino system with alerts, exhaust fan, servo gas shutoff and phone monitoring.
- [3-Digit Digital Password Lock](https://github.com/munshi-rishad/DLC-3-Digit-Digital-Password-Lock) – logic-gate password lock with D flip-flops and BCD validation, made in Multisim.

**Software Engineering**
- [Traditional Model-Driven Banking System](https://github.com/munshi-rishad/Software-Traditional-Model-Driven-Banking-System) – V-Model project report with SRS, UML, Figma wireframes and Git workflow.
